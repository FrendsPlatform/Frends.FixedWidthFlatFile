# Changelog

## [2.0.0] - 2026-09-10
### Changed
- Target framework updated to net8.0.
- Added `Options` parameter with `ThrowErrorOnFailure` and `ErrorMessageOnFailure` properties to control error handling behavior.
- `Result` now includes `Success` and `Error` properties in addition to `Data`.
- Renamed the `data` parameter to `input` for consistency with other Frends Tasks.
